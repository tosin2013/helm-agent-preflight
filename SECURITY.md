# Security Reporting

Report security vulnerabilities to **cncf-helm-security@lists.cncf.io**.

Do NOT open a public GitHub issue for security vulnerabilities.

PGP encryption is available. We acknowledge reports within 3 business days.

Reporter credit is offered with permission. CVE IDs are pursued after public
disclosure.

For general Helm security policy, see:
https://github.com/helm/community/blob/master/SECURITY.md
